# Pen Assist – ปุ่มลอยแบบ S Pen สำหรับ Honor Pad V9 + Magic-Pencil 4s

## ฟีเจอร์
| เมนูปุ่มลอย | เทียบกับ S Pen |
| --- | --- |
| ✍️ เขียนบนหน้าจอ | Screen Write |
| ✂️ เลือกและครอบตัด | Smart Select |
| 📝 โน้ตด่วน | Create Note |
| 🔍 ค้นหา/แปลหน้าจอ | Translate / Bixby Vision (ใช้ Google Lens) |
| 📸 จับภาพหน้าจอ | – |

ในหน้าวาด: ปากกาไวต่อแรงกด, ไฮไลต์, ยางลบ, เปลี่ยนสี/ขนาด, เลิกทำ,
โหมดเขียนด้วยปากกาอย่างเดียว (กันฝ่ามือ), บันทึกไปที่ Pictures/PenAssist, แชร์, ส่งไป Google Lens

## วิธี build บน GitHub (ไม่ต้องลง Android Studio)
1. สร้าง repository ใหม่บน GitHub เช่น `PenAssist` (เลือก Private ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ด้วยปุ่ม **Add file > Upload files**
   ถ้าโฟลเดอร์ `.github` ไม่ถูกอัปโหลดไปด้วย ให้กด **Add file > Create new file**
   ตั้งชื่อเป็น `.github/workflows/build.yml` แล้ววางเนื้อหาจากไฟล์นั้นลงไป
3. ไปที่แท็บ **Actions** รอจนงาน "Build APK" ขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 3–6 นาที)
4. กดเข้าไปในงานนั้น เลื่อนลงไปที่ **Artifacts** แล้วดาวน์โหลด `PenAssist-apk` (ได้เป็น .zip ที่มีไฟล์ .apk อยู่ข้างใน)
5. ส่งไฟล์ .apk เข้าแท็บเล็ต แล้วกดติดตั้ง (อนุญาตให้ติดตั้งแอปจากแหล่งที่ไม่รู้จัก)
6. ถ้างานขึ้นกากบาทสีแดง ให้กดเข้าไปดู log แล้วคัดลอกข้อความ error มาให้แก้

## วิธี build ด้วย Android Studio (ทางเลือก)
1. ติดตั้ง Android Studio (เวอร์ชันล่าสุด)
2. File > Open แล้วเลือกโฟลเดอร์ PenAssist รอให้ Gradle sync เสร็จ
   (ถ้าระบบเสนอให้อัปเกรด AGP/Gradle กดยอมรับได้)
3. บนแท็บเล็ต: ตั้งค่า > เกี่ยวกับแท็บเล็ต > แตะ "หมายเลขรุ่นที่สร้าง (Build number)" 7 ครั้ง
   > กลับไปเปิด "ตัวเลือกสำหรับนักพัฒนา" > เปิด "การแก้ไขข้อบกพร่อง USB"
4. ต่อสาย USB แล้วกด Run ▶ ใน Android Studio
   (หรือสั่ง Build > Build APK(s) แล้วคัดลอกไฟล์ APK ไปติดตั้งเอง)

## ตั้งค่าครั้งแรกบนแท็บเล็ต
1. เปิดแอป Pen Assist แล้วกด "เปิดหน้าการช่วยการเข้าถึง" จากนั้นเปิดบริการ "Pen Assist – ปุ่มลอยปากกา"
2. ถ้าติดตั้งจากไฟล์ APK แล้วสวิตช์เป็นสีเทา (Restricted setting):
   ไปที่ ข้อมูลแอป > ⋮ > "อนุญาตการตั้งค่าที่ถูกจำกัด" แล้วลองใหม่
3. ป้องกัน MagicOS ปิดแอป: ตั้งค่า > แบตเตอรี่ > การเปิดแอป > Pen Assist > จัดการด้วยตนเอง (เปิดทุกตัวเลือก)
   (ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชัน MagicOS)

## ข้อจำกัดที่ควรรู้
- ปุ่มบน Magic-Pencil 4s ถูกระบบ MagicOS จัดการเอง แอปนี้จึงอาจรับสัญญาณปุ่มไม่ได้
  (โค้ดรองรับการกดปุ่มข้างค้างให้เป็นยางลบ ถ้าระบบส่งสัญญาณ BUTTON_STYLUS_PRIMARY มาให้)
- เคอร์เซอร์ตอนลอยปากกาจะแสดงเฉพาะเมื่อปากการายงาน hover event
- แอปธนาคาร/แอปที่ป้องกันการจับภาพ จะใช้ "เขียนบนหน้าจอ" หรือ "ครอบตัด" ไม่ได้
- ระหว่างใช้หน้าวาด ล็อกการหมุนจอไว้ ถ้ากดปิดหรือย้อนกลับ งานที่ยังไม่บันทึกจะหายไป
- ทำ Screen-off memo (เขียนตอนจอดับ) และ Air Actions ไม่ได้ เพราะต้องใช้สิทธิ์ระดับระบบ
- โค้ดนี้เป็นต้นแบบ (prototype) ที่ยังไม่ได้ทดสอบบนเครื่องจริง ถ้า build แล้ว error ส่งข้อความ error มาให้แก้ได้

## โครงสร้างโค้ด
- `PenAssistService.kt` – ปุ่มลอย + เมนู + จับภาพหน้าจอ (AccessibilityService, ไม่อ่านเนื้อหาบนจอ)
- `EditorActivity.kt` – หน้าวาด/ครอบตัดแบบเต็มจอ + แถบเครื่องมือ
- `DrawingView.kt` – ผืนวาดที่ไวต่อแรงกด + ระบบกันฝ่ามือ + ยางลบ + กรอบเลือกพื้นที่
- `ImageUtils.kt` – บันทึกรูป / แชร์ / ส่งไป Google Lens
- `MainActivity.kt` – หน้าตั้งค่า
